security Role Enforcement in Express Middleware

The system never trusts client-supplied roles. Authentication reads HTTP-Only cookies, decrypts cryptographic JWT tokens, and executes a database lookup against MongoDB Atlas to query the user's verified role before routing.

STUDENT ATTEMPTS /faculty/*
• 403 Forbidden
Express middleware rejects and redirects to /student/dashboard
FACULTY ATTEMPTS /admin/*
• 403 Access Denied
Express middleware denies access and enforces advisor boundary
DATABASE FILTERING
• Backend Query Scoping
APIs strictly return only assigned records; never filtered in React
